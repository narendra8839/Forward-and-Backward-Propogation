# Forward and Backward Propagation Analysis

## 📌 Project Overview
This project implements **forward propagation** and **backpropagation** using **TensorFlow / Keras**. The objective is to understand the underlying mechanisms of neural network training and analyze how hyperparameter adjustments—specifically **learning rate** and the **number of epochs**
---

## 🎯 Objectives
* Implement a Deep Neural Network using TensorFlow/Keras.
* Perform forward propagation to compute predictions and loss values.
* Perform backpropagation (gradient descent) to update network weights.
* Analyze model performance across different:
  * **Learning Rates** (e.g., $0.1$, $0.01$, $0.001$, $0.0001$)
  * **Number of Epochs** (e.g., $10$, $50$, $100$, $200$)
